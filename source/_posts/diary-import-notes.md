## 起因

翻 Obsidian 的时候发现，`D:\ai-demo` 底下居然躺着 **10 个仓库**。

有的是学习路径，有的是项目文档，有的是某天晚上随手记的。加起来几百篇，全都只在本地活着。

博客空着也是空着，不如搬过去。

## 第一版脚本：直接复制

```python
shutil.copy(src, f"source/_posts/{slug}.md")
```

结果当然是灾难：

- `[[双链]]` 原样出现在正文里
- `![[图片]]` 全部裂图
- 每篇开头都有一段手写目录，和主题右侧的 TOC 打架
- front-matter 全丢

## 七版之后

最终版本处理了这些：

| 问题 | 处理方式 |
| --- | --- |
| wiki 链接 | `[[目标\|别名]]` → 别名，`[[目标]]` → 目标 |
| 图片 | 按 md5 重命名，拷到 `source/img/posts/<slug>/` |
| 手写目录 | 识别连续的 `- [[#锚点]]`，连标题一起删 |
| callout | `> [!question]` → `> **❓ 问题**` |
| PDF 提取的怪字 | `⼯`（康熙部首）→ `工`，用 NFKC 逐字修 |
| 标题被硬换行 | 检测"标题 + 空行 + 短行"的结构，拼回去 |
| `{{ }}` 模板语法 | 包一层 `{% raw %}`，否则 Hexo 会尝试解析 |

那个康熙部首的问题特别隐蔽——**看起来一模一样，搜索搜不到，字体会掉**。7000 多个字符，肉眼根本发现不了。

## 一个笨但有效的判断

导入之前问自己三个问题：

1. 这篇**脱离上下文**还读得懂吗？
2. 半年后我还会想翻它吗？
3. 里面有**具体的东西**吗（命令、数字、报错）？

三个都是"是"才导。

结果是：几百篇里只导了 30 篇。剩下的留在 Obsidian 里，它们本来就不该见人。

## 收获

不是"博客终于有内容了"，而是**重新读了一遍自己写过的东西**。

有些笔记当时觉得很普通，现在看反而有价值；有些当时写得很得意，现在看全是正确的废话。

后者删掉了。
